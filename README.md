# Tata Play Subscriber Retention & Support Copilot

## Overview
An end-to-end Subscriber Retention & Support Copilot built as a single reproducible repository covering data auditing and cleaning (Part A), churn prediction (Part B), customer segmentation and revenue-at-risk prioritization (Part C), and a grounded LLM support and retention brief pipeline (Part D).

## Reproduce
1. `python -m venv .venv`
2. `.venv\Scripts\Activate.ps1` (or `source .venv/bin/activate` on macOS/Linux)
3. `pip install -r requirements.txt`
4. `python generate_data.py`
